# divisorsコマンド
標準入力から読み込んだ数字の約数を答える。

## 使い方
- 1 Code(緑のボタン)をクリック。
- 2 HTTPSをクリックし、URLをコピー。
- 3 任意のディレクトリに移動し、$ git clone <さっきコピーしたURL> を実行する。
- 4 $ echo 約数を知りたい数字 | ./divisors で実行。
- 5 結果が表示されます。

## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.9~3.13

## テスト環境
- Ubuntu 24.04 LTS
