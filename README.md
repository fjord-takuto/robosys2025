# divisorsコマンド
標準入力から読み込んだ数字の約数を答える。

## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.9~3.13

### テスト環境
- Ubuntu 24.04 LTS

このソフトウェアパッケージは、3条項BSDライセンスの下、再頒布および使用が許可されます。
